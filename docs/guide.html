SETUP GUIDE · NO ROOT / NO PC

Set up Shizuku & fix Step 3.

DrionTune uses Shizuku to run system-level commands without root. Follow the 3 steps below, or jump straight to your phone brand if Step 3 gets stuck on Pending.

Fix Step 3 by Brand 3-Step Setup
01 / FIRST-TIME SETUP

Three steps. Takes under 2 minutes.

Requires Android 11 or newer and an active Wi-Fi connection during pairing.

STEP 01

Install Shizuku

  1. Install Shizuku from Google Play Store or shizuku.rikka.app.
  2. Open Shizuku once and leave it ready in the background.
STEP 02

Start Shizuku via Wireless Debugging

  1. Open Settings → About Phone and tap Build Number (or OS Version) 7 times until Developer Options unlocks.
  2. Open Developer Options, then turn ON USB Debugging and Wireless Debugging.
  3. In Shizuku, tap Pairing → Notification, then tap Pair device with pairing code inside Wireless Debugging.
  4. Enter the 6-digit code in the Shizuku notification, go back to Shizuku, and tap Start until it says Shizuku is running.
STEP 03

Allow DrionTune Access

  1. Open DrionTune and tap Allow when Shizuku asks for permission.
  2. Wait a few seconds for Step 3 to turn green (Ready).
  3. If Step 3 stays Pending ("Shell service did not respond") or Shizuku shows "The permission of adb is limited", apply your phone brand fix below.
02 / FIX STEP 3 BY PHONE BRAND

Stuck on Step 3? Unlock your brand's ADB toggle.

Some Android skins block Shizuku from spawning DrionTune's shell service until a hidden Developer Options toggle is turned on.

OPPO · REALME · ONEPLUS

ColorOS / Realme UI / OxygenOS

Fixes Shizuku: The permission of adb is limited and Step 3 Pending.

  1. Open Settings → Developer Options.
  2. Scroll near the bottom and turn ON Disable permission monitoring.
  3. Set Battery usage for Shizuku and DrionTune to Allow background activity.
  4. Force stop Shizuku, start it again, then tap Retry Bind in DrionTune.
XIAOMI · REDMI · POCO

MIUI / HyperOS

Fixes silent bind timeouts and permission blocks.

  1. Open Developer Options and turn ON USB debugging (Security settings) (requires SIM card + Mi Account).
  2. In App Info for Shizuku & DrionTune: set Battery saver to No restrictions and enable Autostart.
  3. Restart Shizuku, then tap Retry Bind in DrionTune.
TECNO · INFINIX · ITEL

HiOS / XOS (e.g. Tecno POVA)

Android's Battery "No restrictions" alone is often not enough on HiOS.

  1. Keep USB debugging ON alongside Wireless debugging.
  2. Check near the bottom of Developer Options for Disable permission monitoring and turn it ON if shown.
  3. Open Phone Master → App Management / Auto-start and allow both Shizuku and DrionTune.
  4. Open Shizuku → Authorized apps to confirm DrionTune is ON, restart Shizuku, then tap Retry Bind.
VIVO · IQOO · SAMSUNG

Funtouch OS / OriginOS / One UI

Fixes background service kills and restricted ADB.

  1. Vivo / iQOO: Turn ON USB debugging (Security settings) or Disable permission monitoring in Developer Options, and allow High background power consumption.
  2. Samsung: Set Battery to Unrestricted for Shizuku and DrionTune so One UI does not put them to sleep.
03 / QUICK CHECKLIST

Still not binding?

Verify these three things before retrying.

01Did you restart Shizuku after changing Developer Options?

Shizuku reads ADB permissions when its service starts. Always stop and re-start Shizuku after toggling Disable permission monitoring or USB debugging (Security settings).

02Is Wi-Fi still connected?

Android turns off Wireless Debugging if Wi-Fi disconnects. Keep Wi-Fi on while starting Shizuku.

03Is DrionTune enabled inside Shizuku?

Open Shizuku → Authorized apps and make sure DrionTune is toggled ON, then tap Retry Bind inside DrionTune.
